# Regalo para Paula ❤️

Página web romántica para presentar una tarjeta de regalo de H&M por $100.000 COP y una invitación a una cita este sábado.

## Estructura

```text
regalo_paula/
├── index.html
├── style.css
├── script.js
└── assets/
    └── tarjeta-hm.png
```

## Cómo subirla a GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `assets`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub genere la página.

No necesitas instalar Node, React ni ningún framework.

## Personalizar

- El texto principal está en `index.html`.
- Los colores están definidos al inicio de `style.css`.
- La imagen de la tarjeta está en `assets/tarjeta-hm.png`.
- Las animaciones e interacciones están en `script.js`.

La página es responsive y está pensada especialmente para verse bien desde un celular.
